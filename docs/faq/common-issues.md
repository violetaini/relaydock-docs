# 常见问题排查 (FAQ)

本章节汇总了日常使用中常见疑问与故障排查技巧。

---

## 1. 为什么 DDNS 下拉菜单里显示当前未匹配到证书？
- **原因**：节点域名输入框中当前填写的是 IP 地址（例如 `158.51.111.32`），或者尚未填写属于证书泛域名后缀的二级/三级域名。
- **解决方法**：点击输入框下方的快捷证书标签（如 `[ *.chitanda.net ]`）自动生成子域名，即可秒级匹配。

## 2. 账号被禁用时登录为什么提示“账号已被停用”？
- RelayDock 在最新版本中强化了安全交互。当管理员在用户管理中将某账号设为停用时，前台将明确提示「该账号已被管理员停用，请联系管理员」，而不是含糊的「账号或密码错误」。

## 3. 为什么 Xray 快捷操作里没有“单独立即更新 Xray”按钮？
- 当前服务器处于 **全托管（内嵌核心）** 模式。
- Xray 引擎直接编译在 Agent 内部，随 Agent 升级而升级。只需在卡片点击「Agent 管理 -> 升级 Agent」即可同步更新 Xray。

## 4. 节点卡片离线排查流程
1. SSH 登录节点，执行 `systemctl status relaydock-agent` 检查服务是否处于 `active (running)` 状态；
2. 执行 `journalctl -u relaydock-agent -n 30` 查看是否有网络握手或 Token 认证失败日志；
3. 检查节点服务器到控制端公网端口的連通性。
