# 常见问题速查

本页提供快速定位入口；需要完整步骤时查看[分层排错](/docs/operations/troubleshooting)。

## 安装与访问

### 默认密码是什么？

首次访问通过初始化向导创建管理员，没有所有实例通用的默认密码。已有安装突然进入初始化页面时，先检查数据路径/挂载，不要立即重新初始化。

### 脚本支持 Alpine 就等于 OpenRC 可直接运行吗？

不等于。安装器识别包管理器与系统服务托管是两回事，当前服务流程依赖 systemd。优先使用经过验证的 systemd 环境，或采用适合自己的容器/手工托管方案。

### 网页 502/504 要加大超时吗？

先查后端监听、进程和外部依赖。504 可能是服务端请求身份服务卡住，单纯延长超时不会解决网络根因。见[HTTPS 排错](/docs/install/https#常见症状)。

## 登录与权限

### 账号停用了为什么曾经提示账号密码错误？

当前版本会在凭据验证正确后返回停用原因；错误凭据仍使用通用提示。旧版本请核对[修复范围](/docs/reference/versions)。

### SSO 已登录，为什么没有节点？

SSO 验证身份，不代替 RelayDock 服务授权。检查本地账号映射、授权方式、有效期、额度及凭据部署。

### 登录页为什么先没有第三方按钮又改变？

旧版异步加载品牌/提供商可能造成跳变。当前前端在初始化就绪后再显示表单。若仍复现，核对网页版本、CDN 缓存和静默 SSO 循环。

## 服务器与地址

### Agent 在线了，但代理还是不可用？

继续检查核心、入站、监听端口、防火墙、授权和客户端配置。控制通道与业务通道不同。

### 没有 xray.service 是不是安装失败？

内嵌核心可以运行在 Agent 进程内。检查实际模式、Agent 日志与监听端口，不要重复安装第二个核心。

### 动态公网 IP 会自动更新吗？

当前 Agent 会周期探测并上报；显式域名不会因地址变化被随意覆盖。要让 DNS 解析随 IP 变化，还需[DDNS](/docs/features/ddns)或外部 DDNS。

### 节点域名和服务器地址能写一个吗？

可以在拓扑允许时使用相同主机名，但用途不同。节点域名影响客户端/域名转发，管理地址用于管理连接。见[字段表](/docs/servers/server-fields)。

### 证书能签发，DDNS 为什么不支持？

两者适配独立。当前华为云支持 DNS-01，但内置 DDNS 工厂未接入。见[服务商能力表](/docs/features/dns-providers)。

## 转发与分享

### 任意门入口为什么客户端显示 SS？

入口机制是任意门，客户端协议继承目标 Shadowsocks，两者不冲突。当前 UI 显示绑定与节点类型，见[图解](/docs/nodes/forwarding)。

### 改了目标名称，绑定会变吗？

不会仅凭名字建立或变更关系。应在转发目标选择器中切换并保存，等待远端确认，列表分组随真实绑定更新。

### 目标域名不能编辑怎么办？

已有值来自目标服务器的节点域名，统一到服务器管理修改；没有配置时，可在转发域名模式输入并同步。见[域名操作](/docs/nodes/domains)。

### 分享链接为什么不能直接发管理员版本给用户？

链接包含当前身份的凭据，应按每位用户授权生成。不能用所有者凭据替代个人开通失败。

### 换了域名，手机里的二维码节点会自动变吗？

不会。已导入的单节点是快照，需要刷新订阅或重新生成/导入。新二维码使用当前地址，但历史图片不会更新。

## 运维

### 网卡流量为什么和用户加起来不一样？

整机统计包含维护与其他进程，用户统计是业务归因，口径不同。多跳也可能产生多机消耗。见[计量](/docs/features/traffic)。

### Agent 升级 exit status 1 怎么办？

展开单机日志，查第一个下载/校验/架构/权限/重启错误。不要只复制汇总信息。见[Agent 升级排错](/docs/operations/update#agent-升级失败怎么查)。

### GitHub 已同步，为什么检查不到新版本？

提交源码与创建 Release 是两个动作；安装器按正式发布资产更新。见[版本与发布](/docs/reference/versions)。

### 恢复提示暂存成功，数据没变化？

恢复先校验并暂存，服务重启时才应用。先备份当前数据，按[恢复流程](/docs/operations/backup)安排维护，避免误以为失败而重复上传。
