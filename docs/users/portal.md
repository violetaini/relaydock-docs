# 用户门户、自助开通与订阅

本页面向普通用户。管理员准备工作见[服务授权](/docs/users/authorization)。

## 登录后先看什么

查看账号状态、套餐/授权有效期、剩余额度和可用服务。没有列出服务器或节点时，先联系管理员核对授权，不要尝试其他用户的链接。

外部 SSO 能让你完成身份验证，但仍需要 RelayDock 内部账号和服务范围正确匹配。

## 自助开通节点

1. 打开可用服务器/自助节点列表。
2. 选择授权内的发布项或协议组合。
3. 核对速率、连接数、流量和有效期提示。
4. 提交开通并等待部署结果。
5. 节点可用后再获取订阅或二维码。

若显示不可开通原因，应根据提示处理额度、协议、有效期或 Agent 状态。已有开通项不应反复创建。

## 获取客户端配置

| 客户端使用方式 | 选择 |
| --- | --- |
| 支持完整订阅 | 复制适配该客户端的订阅地址 |
| 仅导入单个节点 | 使用节点分享 URI 或二维码 |
| 需要完整规则与分组 | 使用配置生成器及合适模板 |

Mihomo/Clash、sing-box、Shadowrocket 等客户端对格式与协议支持不同。不要将一种客户端的 YAML 原样导入另一种客户端。

## 更新与地址变化

服务器更换域名、端口、凭据或授权后，需要刷新订阅。单节点二维码只是当时的配置快照，不会在手机里自动变成新地址。

刷新仍旧时，核对客户端更新结果、订阅缓存、所选账号及是否导入了相同名称的旧条目。

## 隐私与交付

订阅地址、节点密码、私钥和二维码均可提供访问能力。分享给他人可能消耗你的额度并影响连接限制；别把完整链接放到公开测速网站、群聊截图或 issue。

如果怀疑泄露，联系管理员轮换对应凭据/令牌，并在客户端删除旧配置、重新获取。

## 使用异常怎么反馈

提供发生时间、客户端名称和版本、网络运营商、节点展示名称、报错及是否所有节点都失败。隐藏分享 URL 中的令牌、密码和个人信息。管理员才能据此区分授权、端口、协议和线路问题。
