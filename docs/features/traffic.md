# 流量统计、重置与配额

RelayDock 内置了高精度的流量计量与限额断流保护机制，支持多维度口径选择。

---

## 流量来源口径对比

1. **系统网卡口径（VPS 计费口径，推荐）**：
   - 直接读取 Linux `/sys/class/net` 真实网络设备收发字节数。
   - **优点**：与各云服务商（甲骨文、搬瓦工、DMIT、AWS 等）后台账单计费口径完全吻合，包含系统自身流量及所有进程开销。
2. **Xray 节点聚合口径**：
   - 仅统计通过 Xray 代理入站/出站流经的业务数据包。
   - **优点**：精准过滤掉节点系统维护、测速、心跳等杂散流量。

---

## 自动化策略

- **每月重置日**：设定每月指定的自然日（1~31 日，0 表示不重置），重置日零点自动清零已用流量。
- **流量统计方向**：支持「上行 + 下行」、「上行/下行取较大值」、「仅上行」或「仅下行」等多种云厂商计费模型。
- **限额超量熔断**：达到流量上限时，系统自动暂停节点服务，防止产生天价账单。
