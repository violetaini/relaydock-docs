# 流量来源、计费与重置

先确定观察范围：**服务器整机流量、节点业务流量和用户计费**不是同一个统计。将它们直接相加或互相替代，会造成误判。

## 三层口径

| 观察范围 | 数据来源 | 用于什么 |
| --- | --- | --- |
| 服务器：系统网卡 | Agent 上报的主机收发计数 | 观察整机网络使用，含其他进程和维护流量 |
| 服务器：Xray 聚合 | 所属节点的业务计数 | 观察受管代理业务 |
| 用户/节点/套餐 | 可归因的业务统计与对应政策 | 用户额度、节点明细和服务限制 |

服务器选择“系统网卡”不会把整机其他进程的流量自动归到某个用户，也不会改写用户套餐的计费方式。

## 为什么与厂商账单不完全一致

网卡计数更接近主机网络观察，但厂商可能采用单向出站、计费倍率、不同时间边界、虚拟网络层或取整规则。测速、系统更新、备份和其他容器也会产生网卡流量。因此不能承诺与任意厂商账单完全一致。

## 统计方向

服务管理可按当前界面选择：

| 方式 | 含义 |
| --- | --- |
| 上行 + 下行 | 两个方向累加 |
| 上行 / 下行取较大值 | 按对应实现取较大方向，需结合周期数据理解 |
| 仅上行 | 仅统计选定上行方向 |
| 仅下行 | 仅统计选定下行方向 |

先确认这里的方向是服务器/业务哪个观察角度，再与厂商“出站”对照。不要根据客户端的下载动作直接推断服务器字段。

## 已用流量校准与限制

导入旧环境或周期中途接入时，可按界面提供的已用值/偏移校准。修改前记录原值、来源和时间；校准不是删除历史真实流量，也不应让负值或重复修正掩盖消耗。

服务器限额、用户限额、节点限额和转发限额分别维护。`0` 是否代表不限应按对应字段提示判断，不能将所有数值字段同等处理。

## 重置与有效期

| 设置 | 范围 |
| --- | --- |
| 服务器每月重置日 | 服务器统计周期，`0` 表示不自动重置 |
| 套餐/用户周期 | 对应用户服务的计费周期 |
| 续期套餐 | 延长有效期，不应默认等于流量清零 |
| 固定节点周期 | 按该节点授权政策处理 |

月底不存在的日期、时区和已有周期状态应以当前执行结果为准。准备正式计费时，使用测试账号验证短周期或小额度，并记录控制端时间；不要承诺任意负载下整点零延迟执行。

## 流量为零或突然变化

- 检查统计来源、时间筛选和基线日期。
- 检查 Agent 是否正常上报，核心统计是否启用，用户/节点是否可归因。
- 主机重启使网卡累计计数回退时，需要重建基线，不能把回退差额当作负流量。
- 切换网卡/Xray 来源后，不应将前后值当同一口径连续比较。
- 多跳转发会在多台机器产生网络消耗，不直接等于用户应付的流量总和。

限额执行有采集和控制延迟，不能替代云厂商预算、流量告警与账单保护。
