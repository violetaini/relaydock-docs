# 前置伪装与防 CF 撞墙

为了保证节点通信在复杂公网环境下的长效稳定性，RelayDock 提供原生 443 端口接管与前置伪装防护。

---

## 443 端口接管模式

- **不接管（纯 WSS / 标准）**：Xray 独立监听入站端口。
- **Tunnel 模式**：通过前置反代接收 443 流量，匹配预设路径转发至 Xray，非节点流量转至伪装站点。
- **Fallback 模式**：Xray 优先监听 443，TLS 解密后将非代理流量回落（Fallback）至本地静态网页或指定伪装目标。

---

## 防 Cloudflare CDN 撞墙保护

在配置「反向代理指定伪装网站」时，RelayDock 会自动检测目标域名是否套用了 Cloudflare CDN：

::: warning 安全红线
严禁反向代理套了 Cloudflare CDN 的站点！
如果反代目标套了 CF，全网扫描探针会将您的 VPS 探测为免费的“CF 优选节点”，导致您的 VPS 遭遇海量恶意扫射流量，甚至被服务商封停。
:::
RelayDock 控制台会在保存前进行实时域名解析安全预检，提前拦截此类高危配置。
