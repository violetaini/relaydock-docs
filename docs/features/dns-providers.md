# DNS 服务商接入规范

RelayDock 内置了对全球主流 DNS 提供商的 API 深度适配，作为 SSL 证书自动验证（ACME DNS-01）与动态 DNS（DDNS）双引擎的核心驱动。

---

## 主流服务商接入配置清单

### 1. 华为云 DNS (Huawei Cloud)
- **适用场景**：国内备案域名、海外托管域名、企业级高可用解析。
- **获取凭据**：
  1. 登录华为云控制台，进入「统一身份认证服务 (IAM)」->「我的凭证」。
  2. 在「访问密钥」页签，点击「新增访问密钥」，下载包含 `Access Key ID` (AK) 与 `Secret Access Key` (SK) 的凭证文件。
- **权限要求**：需赋予 `DNS Administrator` 权限。

### 2. Cloudflare
- **适用场景**：全球 CDN 加速、个人域名管理、免备案出海。
- **获取凭据**：
  1. 登录 Cloudflare Dashboard，进入右上角「我的个人资料」->「API 令牌」。
  2. 点击「创建令牌」，选用「编辑区域 DNS」模板。
  3. 权限包含：`区域 - DNS - 编辑`，区域资源选择「包含 - 所有区域」或指定特定域名。
  4. 复制生成的专属 `API Token`（注意不是 Global API Key）。

### 3. 腾讯云 DNSPod
- **适用场景**：国内主流解析、企鹅系产品联动。
- **获取凭据**：
  1. 登录腾讯云控制台，访问「访问管理」->「API 密钥管理」。
  2. 新建密钥，获取 `SecretId` 与 `SecretKey`。
  3. 或在 DNSPod 控制台创建专用的「DNSPod Token (ID + Token)」。

---

## 凭据安全存储机制
所有填入的 DNS API Secret 均在控制端内部通过行业标准的 AES-256-GCM 算法加密持久化存储，内存使用后即刻抹除，绝不随日志或前台网络请求明文输出。
