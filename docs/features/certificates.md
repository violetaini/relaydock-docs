# SSL 证书管理与自动续期

RelayDock 提供开箱即用的 SSL 证书生命周期管理，涵盖全自动 DNS-01 签发与外部已有证书手动托管。

---

## 两种证书模式

### 1. DNS-01 全自动签发与续期
- **支持 CA**：Let's Encrypt、Let's Encrypt Staging。
- **验证方式**：DNS-01（自动在您的 DNS 服务商处写入 `_acme-challenge` TXT 记录，验证完成后自动清除）。
- **优势**：支持泛域名证书（如 `*.chitanda.net`），无需占用宿主机 80 端口，且到期前 30 天自动静默续签。

### 2. 手动上传证书（PEM / KEY）
- 若您已有从阿里云、腾讯云或其他 CA 机构购买/下载的商业 SSL 证书，可直接将证书公钥（`fullchain.pem`）与私钥（`privkey.pem`）粘贴上传。
- **关联 DNS 服务商**：支持手动上传的证书关联具体的 DNS 服务商，便于在 DDNS 节点配置中实现全自动复用与域名推导。
