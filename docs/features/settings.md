# 系统设置与品牌配置

当前系统设置按 **基础、订阅、安全、权限、快捷登录、Telegram Bot、通知、维护**组织。不同版本可能有字段增减，以实际页面为准。

## 基础

维护公开 URL、主题、登录壁纸、项目名称、Logo、浏览器图标和采集间隔。公开 URL 应是用户和 Agent 实际使用的规范 HTTPS 地址。

变更公开入口后，应复查反代、证书、OAuth 回调、Agent 命令和对外订阅链接。仅修改展示名称不会修改这些真实地址。

### 登录外观与自动 SSO

登录主题、背景和品牌是展示配置；自动检测 OIDC 登录状态是认证流程配置。启用自动检测前先手工完成一次 OIDC 往返，确保没有登录循环。

当前登录表单会等待品牌、登录方式、验证码及静默登录检查就绪，减少先显示不完整表单再跳变的情况。旧版仍可能存在差异，见[版本范围](/docs/reference/versions)。

## 订阅

配置外部同步、节点匹配、缓存、兼容模式、短链接和 Proxy Provider 等。先在测试用户和测试客户端验证，避免全局修改直接影响全部订阅。

缓存时间会影响变更传播，不能仅凭刷新浏览器判断客户端已取得最新配置。参见[模板与规则](/docs/features/templates)。

## 安全和权限

查看登录限制、验证码、API 相关配置和权限策略。权限变更应由后端校验承担，隐藏按钮本身不构成访问控制。

全局 API 令牌拥有较高管理能力，只用于受控管理集成；普通用户集成优先使用其个人令牌及权限范围。见[API](/docs/reference/api)。

## 快捷登录

支持 GitHub、Google 与通用 OIDC 的配置，回调地址以页面显示值为准。第三方账号自动注册与按邮箱自动关联都是独立开关，启用前阅读[SSO 接入](/docs/security/sso)。

## Telegram Bot 与通知

Bot Token、管理员 Telegram ID 和 WebApp 入口需按当前字段配置。本机 Mini App 预览是开发辅助，不应理解为公网免认证入口。

通知配置和 Bot 服务并非同一个开关，需分别测试。见[通知与探针](/docs/features/observability)。

## 维护

系统更新、备份/恢复及调试能力在维护相关入口。更新前核对部署方式；备份恢复会替换数据，不能把普通配置回退与恢复旧数据混为一谈。

## 保存失败或部分加载失败

设置页可能分批加载与保存多个配置。若出现加载失败，应先恢复 API 连通再保存，避免默认值覆盖未加载的真实设置。保存后重新打开页面核对持久化值，并按具体功能测试。
