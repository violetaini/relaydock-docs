# 动态 DNS (DDNS) 自动化

RelayDock 内置了企业级动态域名解析（DDNS）引擎。当节点的公网 IP 发生变动时，面板将自动感知并调用 DNS 服务商 API 同步更新 A / AAAA 记录。

---

## 域名与 DDNS 解析模式

在「添加服务器」或「编辑服务器」时，系统提供两种清晰的模式：

```text
[ 🌐 输入现成域名 ]             [ ☁️ 启用本面板 DDNS 服务的域名 ]
使用已有外部解析或固定公网域名    动态公网 IP 变动时自动更新 A/AAAA 解析
面板不主动更新 DNS 记录         支持双栈 IPv4 / IPv6 自动同步
```

---

## 智能证书快速引用（解决多证书困境）

当您在控制台管理了多张泛域名证书（如 `*.chitanda.net`、`*.chitanda.org`）时，RelayDock 提供极速辅助：

- **快捷标签（Chips）**：当证书数量较少（<= 3 个）时，输入框下方直接展示根域名标签。
  - 点击 `*.chitanda.net`，系统自动结合当前服务器名称提取前缀（如 `ddpsjp`），一键拼接为 `ddpsjp.chitanda.net`！
- **带即时搜索的浮层（Searchable Popover）**：当证书较多时，自动收起为 `从已签发证书选取 (N) ▾` 按鈕，支持输入关键字秒级过滤，即使有几十张证书也绝不会撑破表单。

---

## 实时诊断与防呆引导

- **IP 地址智能警示**：若您在 DDNS 域名输入框中填入了 IP 地址（如 `158.51.111.32`），面板会立即弹出警示，提醒您 DDNS 必须填写完整域名才能动态更新解析。
- **证书匹配成功状态**：输入域名后，面板自动计算泛域名后缀，即时显示匹配证书及复用的 DNS 服务商（如华为云、Cloudflare、DNSPod 等）。
