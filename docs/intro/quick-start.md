# 快速开始

欢迎使用 **RelayDock**！RelayDock 是一套为高性能节点代理、中继转发与多服务器运维量身打造的一体化控制管理系统。

---

## 平台核心亮点

1. **统一控制端与轻量 Agent 架构**：
   - 主控端集中处理面板业务、证书申请、DDNS 解析调度与流量报表。
   - 节点服务器只需运行轻量级的 `relaydock-agent`，零外部依赖，极低资源开销。
2. **全托管（内嵌核心）Xray 引擎**：
   - Agent 二进制内部直接嵌入了 `xray-core`，主节点无需单独安装 `xray` 命令或 systemd 守护服务，杜绝进程冲突与版本割裂。
3. **全自动动态 DNS (DDNS)**：
   - 智能识别动态公网 IP（IPv4 / IPv6 双栈），自动匹配关联的泛域名证书，调用 DNS API 完成 A/AAAA 记录的秒级更新。
4. **多级安全防护与伪装反代**：
   - 提供 443 接管模式（Tunnel / Fallback）、静态站点伪装与反向代理目标，并原生提供防 Cloudflare CDN 优选穿透保护。

---

## 主控端（控制面板）部署

通常控制端以 systemd 服务或 Docker 容器方式运行在您的管理主服务器上：

::: tip 生产环境部署建议
控制端推荐配置独立公网域名（如 `relay.example.com`），并通过 Nginx 或 Caddy 配置 SSL 证书与反向代理，以提供现代浏览器所需的安全上下文环境（WebCrypto 支持）。
:::

### 常用端口说明

| 端口 | 用途 | 说明 |
| :--- | :--- | :--- |
| `12889` | 控制端 Web 界面与 API | 默认 HTTP 监听端口，建议通过反向代理转为 HTTPS 访问 |
| `23889` | Agent 默认连接/通信端口 | 用于 Pull 模式或特定通信协议通道 |
| `443` | 前置反代与节点入站伪装 | 启用 WSS / 接管模式时用于承接外部流量 |

## 快速上手 3 步走

1. **登录控制面板**：访问您的控制端地址，完成管理员登录。
2. **接入首台服务器**：进入「服务器管理」，点击「添加服务器」，获取专用的一键接入命令并在节点执行。
3. **启用动态域名或 DDNS**：为节点配置域名，并根据网络环境选择是否开启 DDNS 自动同步。
