# 术语与概念对照

## 资源对象

| 术语 | 含义 | 常见误解 |
| --- | --- | --- |
| 控制端 / 面板 | 提供界面、API、存储和编排的服务 | 面板能打开不代表节点能用 |
| Agent | 受管主机上的执行与上报程序 | Agent 在线不等于业务端口放行 |
| 核心 | 执行代理协议和路由的运行时 | 内嵌核心不要求单独的系统服务 |
| 入站 Inbound | 监听连接的协议配置，通常有唯一 tag | 不是客户端最终访问的网站 |
| 出站 Outbound | 核心向外建立连接的方式 | 配了出站仍需要路由匹配 |
| 节点 | 分发给客户端的连接条目 | 导入节点不自动变成可管理服务器 |
| 受管节点 | 可以关联远端服务器/入站的节点 | 与纯订阅导入条目能力不同 |
| 任意门 AnyDoor / Tunnel | 把 TCP/UDP 转到目标地址与端口的入口 | 客户端通常仍显示目标协议 |
| 多跳转发 | 经过多个受控中继的转发路径 | 不应在任意门绑定中制造循环 |
| 套餐 | 一组可分配服务与限制的组合 | 账号启用不等于套餐有效 |

## 域名与网络

| 字段 / 名词 | 用途 |
| --- | --- |
| 公网 IPv4/IPv6 | 主机对外地址，可由 Agent 探测上报 |
| 服务器地址 / DDNS 地址 | 控制端联系 Agent 等管理连接使用的地址 |
| 节点域名 | 客户端连接及域名转发所用的服务器域名 |
| SNI / Server Name | TLS 握手中的服务器名称，不是任意地址别名 |
| Host | HTTP/WebSocket 的请求主机信息 |
| A / AAAA | 域名的 IPv4 / IPv6 解析记录 |
| DNS-01 | 通过 DNS TXT 记录验证域名控制权的证书挑战 |
| TTL | DNS 缓存有效时间；并非修改后所有客户端立即更新 |
| CDN 代理 | 网站代理服务；不等同于支持任意 TCP/UDP 协议 |

## 安全与计量

**会话令牌**用于登录后请求；**Agent 令牌**用于服务器接入；**订阅令牌**用于取配置；**DNS API 凭据**用于域名操作；**OIDC Client Secret**用于与身份提供商通信。它们用途不同，不能混填或公开。

**上传/下载方向**必须说明观察者：服务器 RX/TX、客户端上/下行和厂商出站计费可能不是同一个方向。**配额**是可使用的总量，**限速**是单位时间速率，**设备/连接限制**由具体实现及协议能力决定，不是同一指标。

## UI 里的“协议”为什么有时不同

一个入口可以同时具有“转发机制 = 任意门”和“客户端协议 = Shadowsocks”。前者描述入口如何送出数据，后者描述客户端用什么凭据和格式连接。参见[转发绑定图解](/docs/nodes/forwarding)。
