# 端口、路径与配置速查

这里列出默认值和发现方法，不代表你的实例必须使用相同端口。所有实际值以安装输出、服务单元和后台配置为准。

## 网络端口

| 用途 | 常见默认 / 取值 | 需要向谁开放 |
| --- | --- | --- |
| 控制端 HTTP/API | TCP `12889`，可修改 | 反代或受控管理来源 |
| 对外 HTTPS | TCP `443` | 实际用户和需要连接的 Agent |
| HTTP 跳转/特定挑战 | TCP `80`，仅按需要 | 网站访问或对应验证请求 |
| Agent 管理 | 常见 `23889`，以模式/生成命令为准 | 仅需要的控制来源，不默认全网开放 |
| 本地到期守卫 | 按安装配置，可能为 `23890` | 按受信控制拓扑限制来源 |
| 节点业务入站 | 创建入站时指定 | 对应客户端及需要的 TCP/UDP |
| 任意门入口 | 转发配置指定 | 客户端/上一跳 |
| 任意门目标 | 目标节点端口 | 下一跳必须允许入口来源连接 |

WebSocket 模式通常依赖 Agent 主动连接控制端，不代表每台节点都需要向全网开放管理端口。云安全组和系统防火墙要分别检查。

## 常见路径

| 内容 | 默认/示例 | 说明 |
| --- | --- | --- |
| 裸机数据 | `/etc/arcway` | 可被已有安装或配置覆盖 |
| Docker 数据 | Compose 当前目录 `./data` | 挂载到容器 `/app/data` |
| 数据库 | `arcway.db` | 由 `DATABASE_PATH` 等配置决定位置 |
| 裸机安装目录 | `/usr/local/bin` | 旧部署可能不同 |
| 受管外置网页 | `current -> releases/<id>` | 需符合完整更新要求 |
| 系统服务名 | `arcway` 或 `relaydock` | 不要凭品牌名猜单元名 |

## 查实际配置

```bash
systemctl list-unit-files | grep -Ei 'arcway|relaydock'
sudo systemctl status arcway --no-pager
sudo ss -lntup
```

需要检查服务单元、进程参数或环境文件时在本机私下查看；其中可能含密钥，不要原样公开输出。

## 常用环境变量

| 变量 | 作用 |
| --- | --- |
| `PORT` | 控制端 HTTP 端口，受配置文件优先级影响 |
| `BIND_HOST` | HTTP 监听主机，例如本机反代时可设 `127.0.0.1` |
| `DATABASE_PATH` | 指定数据库位置 |
| `ARCWAY_WEB_ROOT` | 使用外置网页根目录 |
| `ARCWAY_PANEL_IPS` | 安装/规则相关的主控来源配置，按部署用途核对 |

改环境变量后需要按服务托管方式重载/重启并验证；只在当前终端 `export` 不会自动修改已运行的 systemd 服务。

## 域名填写规范

节点域名填 `node.example.com`；URL 字段才填写 `https://...`；端口填写在单独字段。IPv6、SNI、Host 和 CDN 代理按各字段语义处理，详见[术语](/docs/intro/glossary)。
