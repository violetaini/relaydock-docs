# Nginx 管理模式与原生测速

RelayDock 不仅是代理核心的调度平台，更是一套完备的服务器站点托管与网络质量度量中枢。

---

## 1. Nginx 管理双模式

在添加或编辑服务器时，系统提供两种完全不同的 Nginx 协作模型：

```text
+---------------------------------------+---------------------------------------+
|          Arcway 管理 Nginx             |          复用系统已有 Nginx            |
+---------------------------------------+---------------------------------------+
| - 由面板全自动安装、启动、停止、重载     | - 只下发独立站点配置片段，不控制服务  |
| - 面板统一托管主配置文件与站点目录    | - 严禁覆盖主配置，部署前强制语法预检  |
| - 适合纯净 VPS、专属代理网关节点      | - 适合已有宝塔/aaPanel、LNMP 的环境   |
+---------------------------------------+---------------------------------------+
```

### 生产环境选择建议
- **如果您这台机器只作为代理节点或中继机器**：选择 **Arcway 管理 Nginx**，省心省力，全部由面板代劳。
- **如果您这台机器已经跑了其他业务（如建站、宝塔面板、Uptime Kuma 等）**：务必选择 **复用系统已有 Nginx**！面板只会向独立的目录（如 `/etc/nginx/conf.d/arcway_*.conf`）写入子站点配置，绝不会重启或重置您原有的 Nginx 服务。

## 2. Ookla Speedtest 原生在线测速

为了让管理员真实掌握各节点服务器的物理带宽能力与网络质量，RelayDock 原生深度集成了 Ookla 官方测速引擎。

### 功能亮点
1. **真实网络吞吐**：直接从目标节点向最近的 Ookla 官方骨干测速节点发起全速单线程/多线程压测。
2. **多维度网络指标**：
   - **下载速率**：以 Mbps 呈现，真实评估出口带宽。
   - **上传速率**：以 Mbps 呈现，精准度量回程转发极限。
   - **往返时延 (Latency)**：以 ms 为单位，衡量网络基础响应。
   - **抖动 (Jitter)**：衡量网络波动的关键指标，数值越低代表连接越稳。
   - **丢包率 (Packet Loss)**：直观暴露线路劣化程度。
3. **测速免残留**：测速由 Agent 本地独立拉起，测试完成后自动回收所有网络套接字与临时缓存，零系统负担。
