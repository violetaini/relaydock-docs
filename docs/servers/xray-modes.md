# Xray 核心管理（内嵌 vs 外部）

RelayDock 原生支持两种截然不同但各具优势的 Xray 核心运行模式：**全托管内嵌核心（默认推荐）** 与 **外部接管模式**。

---

## 两种模式对比

| 特性 | 全托管内嵌核心 (Embedded) | 外部接管模式 (External) |
| :--- | :--- | :--- |
| **实现机制** | `xray-core` 作为 Go 依赖直接编译进 Agent | 调用宿主机独立的 `/usr/local/bin/xray` 二进制 |
| **系统守护** | 随 Agent 单进程启动，无需独立 systemd | 依赖系统的 `xray.service` 独立守护 |
| **核心维护** | **随 Agent 更新而自动更新**，免单独打补丁 | 支持在面板下拉菜单中自由选择、安装、升降级版本 |
| **进程冲突** | 零残留，杜绝端口被外部僵尸进程占用 | 需确保宿主机环境干净无其他配置冲突 |
| **推荐人群** | 追求省心、免维护、轻量化的用户 | 原本机器已有官方 Xray、希望定制特定版本的用户 |

---

## 如何切换模式？

1. 进入「**服务器管理**」，在目标服务器卡片下方点击 **编辑（铅笔图标）**。
2. 展开「**高级选项**」，找到「**Xray 管理模式**」。
3. 根据需要选择：
   - **全托管（内嵌核心）**：单进程极简稳定。
   - **接管现有环境（外部模式）**：卡片上将解锁「检查更新」与「选择 / 重装核心」菜单。
4. 点击保存，Agent 收到指令后会自动完成平滑热切换。
